# 真实数据评测：无泄漏口径与当前结果

> 由 `python tools/real_eval.py` 产出，数字全部来自 `results/real_eval.json`（每条结论可对回磁盘产物）。
> 本文记录**方法、纪律、已确认结果、以及尚未查清的异常**——异常不做结论。

## 1. 为什么需要这套口径

工程原有的真实数据结论都不可用于对外声明：

| 口径 | 数字 | 为什么不能用 |
|---|---|---|
| 合成数据同域 | 宏 F1 0.9940 | 自造数据，非真实分布 |
| inSDN 同文件内切分 | 准确率 1.0000 | 46% 精确重复行 + 行序是「正常块+攻击块」拼接 → 必然泄漏 |
| 零样本跨域（旧口径） | 1% 预算下召回 0.0006 | 阈值在合成域定，未做目标域标定 |

## 2. 评测纪律（事前写死）

1. **去重**：先按 `clean_dataframe`（精确）再去重，再在**映射后的 71 维特征子集**上做 3 位有效数字近似去重
   —— 与项目主实验 `dedup_significant_digits=3` 同一开关口径；
2. **切分**：`block`（连续段内前后切分 + purge 间隔）/ `group`（按流身份哈希分组）/ `cross_day`（按真实星期顺序，前 2 天拟合）；
3. **硬门槛**：切分后**行级近重复交集必须为 0**，否则直接报错拒绝出结论（已实测拦下 3,571 行泄漏）；
   身份级组交集按协议如实记录，不冒充身份级隔离；
4. **阈值**：一律取「拟合段正常窗口分数」的 1−预算 分位，**从不使用评估段信息**；
5. **可比性**：主指标是「1% 预算召回」，同时报 **TPR@FPR=1%** 与 **ROC-AUC**（阈值无关，用于消除各臂实测误报率不同带来的不可比），
   并报该工作点**实际达到**的误报率——预算在段间漂移下未必守得住，两个数一起看才算诚实。

## 3. 数值保护（这条踩过坑，必须留着）

| 坑 | 后果 | 处理 |
|---|---|---|
| `np.nan_to_num` 默认把 ±inf 变成 1.8e308 | 平方后溢出，马氏/模型分数被少数维度劫持：inSDN 上深度模型「召回 0.0009」其实是**数值假象** | 显式 `posinf=0, neginf=0` |
| 流统计量重尾，均值/方差被离群点撑爆 | 距离对攻击不敏感（曾出现 AUC≈0 的「完全反相关」假象） | 标准化后 clip 到 ±10（并回报裁剪比例：0.06%~1.35%）；马氏改用**中位数+MAD** |

修掉数值问题后，inSDN 上深度迁移模型的 TPR@FPR=1% 从 **0.0000 → 0.4714**。这说明：
**先排除数值假象，再谈模型好坏**。

## 4. 当前结果（TPR@FPR=1%，同口径可比）

| 数据 / 协议 | 深度迁移(合成scaler) | 重拟合scaler | 稳健马氏(无监督) | kNN(无监督) | 深度+马氏融合 |
|---|---|---|---|---|---|
| inSDN / block | 0.4714 | 0.0001 | 0.4339 | 0.4000 | **0.6311** |
| CIC-IDS2017 / block | 0.0337 | 0.0000 | 0.1953 | **0.3920** | 0.0000 |
| CIC-IDS2017 / cross_day | 0.0456 | 0.0000 | 0.2489 | **0.2745** | 0.0033 |
| CIC-IDS2018 / cross_day | 0.5107 | 1.0000 ⚠ | 0.0000 ⚠ | 0.0000 ⚠ | 0.0021 ⚠ |

已确认的结论（可对外）：

1. **单靠"合成域训练的深度模型 + 合成域阈值"在真实数据上不可用**：跨天/跨实验床口径下 TPR@FPR=1% 只有 0.03~0.05；
2. **无标签的目标域正常流量基线是有效的后备手段**：CIC-IDS2017 上 kNN 达到 0.39（同域）/ 0.27（跨天、且攻击族全部未见）；
3. **融合优于单臂**：inSDN 上"深度分数 + 稳健马氏分数"秩归一化融合达到 **0.6311**，是当前最好的工作点；
4. **预算守不住**：cross_day 下按拟合段 1% 定的阈值，在评估段实际达到 4.7%~5.5% 误报率
   —— 这正是"上线前标定必须做、且必须持续重标定"的直接实测依据。

## 5. 尚未查清的异常（不得当结论）

| 异常 | 现象 | 待排查的假设 |
|---|---|---|
| CIC-IDS2018 / refit_scaler | TPR@FPR=1% = **1.0000**、AUC = 0.9998 | 评估段只有单日（Friday-16-02）且攻击只有 DoS 一族，纯窗口仅 3,015；疑似单日/单族退化，需按「多日评估」重切 |
| CIC-IDS2018 / 无监督基线 | AUC = 0.002~0.02（完全反相关） | 跨日 benign 画像差异过大，导致"评估日正常流量比攻击更偏离拟合段正常分布"；需按天分别拟合正常画像验证 |
| CIC-IDS2017 / 深度模型 | AUC = 0.27~0.33（低于随机） | 合成域与真实域的特征尺度过大，标准化后仍不可比；需做逐特征分布对齐后再评估 |

处置：上述三行在任何材料里都**只作为"待排查"列出**，不得写成模型能力结论。
