## A. 匿名化检查（最高优先级：违规可能直接取消资格）

| # | 检查位置 | 具体要查什么 | 状态 |
|---|---|---|---|
| A1 | 技术报告 PDF | 学校名、学院名、LOGO、指导教师姓名、致谢段落 | ☐ |
| A2 | 技术报告中的路径截图 | `<USER_HOME>\...`、桌面路径、实验室名称 | ☐ |
| A3 | 演示视频 | 终端提示符/窗口标题/浏览器书签/任务栏/桌面文件名校名 | ☐ |
| A4 | 演示视频中的 Git 信息 | `git config user.email`（可能含学校邮箱域名） | ☐ |
| A5 | 答辩 PPT | 母版页脚、模板水印、封面署名 | ☐ |
| A6 | 代码与文档 | README / 注释 / 提交记录里是否残留学校或姓名 | ☐ |
| A7 | 开源仓库信息 | 仓库描述、组织名、贡献者邮箱、LICENSE 版权行 | ☐ |
| A8 | 图表与截图 | 图片元数据（EXIF）、截图中的系统用户名 | ☐ |
| A9 | 网盘分享 | 网盘昵称/头像/文件夹名是否含学校或姓名 | ☐ |
| A10 | 文件名 | 所有提交文件的文件名不得含学校/姓名缩写 | ☐ |

### 推荐的自动检查命令

```powershell
# 1) 在代码与文档里搜索可疑词（把 <校名> <姓名> 换成实际词后执行）
Select-String -Path .\*.md,.\src\*.py,.\tools\*.py,.\docs\*.md,.\competition\*.md `
  -Pattern "<校名>","<姓名>","<指导教师>","大学","学院" -SimpleMatch

# 2) 搜索可能泄漏用户名的绝对路径
Select-String -Path .\*.md,.\src\*.py,.\tools\*.py,.\docs\*.md -Pattern "C:\\Users\\"

# 3) 检查 git 提交者信息（推送公开仓库前务必确认）
git log --format="%an <%ae>" | Sort-Object -Unique
```

> 本工程的产物（`results/`、`logs/`）中会写入绝对路径，**提交前请把这类截图或文件排除**，
> 或把项目整体挪到 `D:\sdn_demo\` 再重新生成一遍产物。

## D. 打包前的文件排除清单（避免误传无权再分发的内容）

推送公开仓库 / 上传网盘时，**必须排除**：

```
# 上游无许可证素材（不随作品公开）
CNN_biLSTM2.py
generate_normal_traffic/
generate_ddos_traffic/

# 无许可证的真实数据集（仅本地评估）
data/real/

# 环境与缓存（体积大、含本机信息）
.venv/
.cache/
_tmp/
__pycache__/
logs/

# 可能含本机路径的产物（如需提交，请重新在无个人信息的路径下生成）
results/*.csv          # 含窗口级预测，行内无个人信息，可保留
artifacts/*/config_used.json   # 含本机绝对路径，建议清理或替换
```

> 建议做法：新建一个干净的发布目录（如 `D:\sdn_demo_release\`），只拷贝需要开放的
> 代码 + 文档 + 图表，在该目录内初始化 git 并推送，避免误带本机信息。

## E. 推送公开仓库的推荐步骤（发布用）

```powershell
# 1) 在干净路径下准备发布内容
mkdir D:\sdn_release
# 拷贝：README.md、LICENSE、NOTICE、requirements.txt、run_all.py、src/、tools/、app/、
#       configs/、docs/、competition/、results/figures/
# 不要拷贝：CNN_biLSTM2.py、generate_*_traffic/、data/real/、.venv/、_tmp/、logs/

# 2) 匿名化配置 git 身份（不要用学校邮箱）
git init
git config user.name  "SDN-IDS Team"
git config user.email "team@example.com"

# 3) 首次提交
git add .
git commit -m "Initial release: SDN anomaly traffic detection (reproducible open-source project)"

# 4) 推送到代码托管平台（平台账号请确认昵称不含学校/姓名）
git remote add origin <你的仓库地址>
git push -u origin main
```
