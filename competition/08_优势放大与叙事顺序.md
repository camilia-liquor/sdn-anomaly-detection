# 优势放大与叙事顺序（不改数字，只改讲法）

> 前提：**所有数字一个都不改**，出处见表末"证据"列。
> 放大靠四件事：**换分母 / 换语言 / 换顺序 / 换媒介**。
> 同一份数据，讲法的差别可以决定评委记住的是"又一个检测模型"还是"一个能落地的系统"。

## 1. 放大四原则

| 原则 | 做法 | 反例（浪费优势） |
|---|---|---|
| **换分母** | 把绝对值换成倍数/占比/差值 | "误报 0.66 次/小时"（听众没有参照，感知不到好） |
| **换语言** | 把算法指标换成业务后果 | "宏 F1 0.9940"（运维听不懂，评委也不缺这个数） |
| **换顺序** | 最强对比放最前（注意力峰值期） | 前 90 秒讲架构图，最有说服力的数字埋在 3 分钟后 |
| **换媒介** | 能"动"的绝不用"表" | 用截图讲"实时检测"、用表格讲"处置闭环" |

## 3. 叙事顺序重排（5 分钟版，只动顺序不动内容）

现有脚本把大屏演示放在 00:50–01:30、把"误报→人力"放在 02:20。问题是最强的对比没落在注意力峰值期。
建议把**两个"30 倍 / 96%"级别的对比**提到前 60 秒：

| 时间 | 讲什么 | 为什么放这里 |
|---|---|---|
| 00:00–00:20 | **开场就给最强对比**：同一份数据换切分方式，数字差 30 倍 | 第一句话就建立"我们和别人的区别" |
| 00:20–00:50 | 一条命令复现 + 130 项自检 | 证明"不是 PPT" |
| 00:50–01:40 | 大屏：检测 → 处置 → 未知 → 复核台（现场拉滑块） | 把"系统感"可视化，四个动效连着走 |
| 01:40–02:20 | **误报→人力换算：22.6~35.6 → 0.36~1.37 工时/天（-96%）** | 这是"能不能用"的判决性数字 |

## 4. 媒介升级（让优势"可感知"而不是"可读"）

1. **凡是倍数关系，屏幕上必须同时出现两个数**（改造前 / 改造后并排），不要只报一个。
2. **每个面板至少有一个"动"的元素**：拓扑脉冲、曲线推进、台账实时新增、复核台计数跳动。
3. **讲边界时紧跟对比**：不要停在"我们做不到 X"，要接"而常见做法是 Y，所以我们选择报 Z"。
4. **能用动画就不用表**：连续确认的价值用"误报计数从 254 跳到 0"的动画讲，比表格强得多。

## 5. 不能碰的三条（与放大不冲突）

放大的是**讲法**，不是**事实**：

1. 合成数据的 0.9940 与真实数据的 0.03~0.63 **分开讲**（两者都对，混起来就假了）。
2. "接口存在 / 桩件测过"与"真机实跑过"**分开讲**（我们有真机 16/16，但没上物理交换机）。
3. **不四舍五入到更好看**（0.034 不讲成"约 0.1"；22.6 不讲成 20）。

> 这三条本身就是优势：本赛道评分原文要求"数据真实有效"，
> 而我们能说"每个数字都能当场打开文件对"。**这种确定性，是放大的天花板。**
