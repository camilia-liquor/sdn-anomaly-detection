# 远程自助试点包 · 发放与回收指引

> 目的：**不组织课堂**也能拿到**真实**的教学试证明数据。参与者在自己电脑上 15 分钟独立完成。
> 适用于：课时已满、没有集中时间、但需要真实用户证据的场景。
> 配套：`回填表_模板.csv`（参与者回填）、`../教学试点问卷.md`（简版卷见 `../教学试点_极简版（10分钟_可远程）.md`）、`../../tools/pilot_analysis.py`（统计）。

## 一、为什么这条路径是合规的

- 参与者**真实存在**、**真实操作**、**真实作答**，只是不集中在教室里；
- 报告中**如实写"远程自助体验（n=__，非课堂试点）"**，不冒称课堂；
- 评分规则要的是"效果验证依据"，**如实标注的小样本远程体验属于有效证据**；
- 不需要签到表、不需要教师签字、不需要占用课时。

## 二、打包（5 分钟）

在项目根目录执行（PowerShell）：

```powershell
$dst = "远程试点包_v1"
New-Item -ItemType Directory -Force $dst | Out-Null
Copy-Item "一键运行.bat" $dst
Copy-Item "requirements.txt" $dst
Copy-Item "competition\回填表_模板.csv" $dst
Copy-Item "competition\教学试点_简版卷与满意度.md" $dst   # 若无此文件，用 教学试点问卷.md 的简版章节
Compress-Archive -Path "$dst\*" -DestinationPath "远程试点包_v1.zip" -Force
```

把 `远程试点包_v1.zip` 发给同学即可（不需要他们装 Python 之外的东西；若目标机没有 Python，请附本工程的 `deploy/` 说明或改用教师机演示回放）。

## 三、给参与者的发放话术（直接复制）

> 麻烦帮我做个小实验，**大约 15 分钟**，全程在你自己电脑上跑，不影响任何东西：
>
> 1. 解压压缩包，双击 `一键运行.bat`，等窗口出现"服务已就绪"（约 1 分钟）；
> 2. 浏览器打开 **http://127.0.0.1:5000** ，按页面提示点两下：先看正常流量，再发起一次攻击，观察"告警 → 阻断"；
> 3. 做 `教学试点_简版卷` 上的 **5 道前测题**（3 分钟）；
> 4. 回到页面再操作一遍，做 **5 道后测题**（同题，3 分钟）；
> 5. 填好 `回填表_模板.csv`（含 5 题满意度）发回给我。
>
> 说明：**完全自愿，随时可以退出**；只填编号不填姓名，数据只用于我们比赛的教学效果统计，不做他用。

## 四、参与者填写（15 分钟）

| 步骤 | 内容 | 预计 |
|---|---|---|
| 1 | 解压 + 启动平台 | 2 min |
| 2 | 观察正常流量 + 发起攻击 + 看阻断 | 8 min |
| 3 | 前测 5 题 | 2 min |
| 4 | 再操作一遍 + 后测 5 题 | 2 min |
| 5 | 填回填表 CSV | 1 min |

## 五、回收与合并（10 分钟）

1. 收集所有人的 `回填表_模板.csv`（每人一个文件，或让每人填同一张表的下一行）；
2. 合并：把每人的一行粘到 `competition/教学试点数据采集表.xlsx` 的「成绩与耗时」与「问卷」两个表中
   （**只保留匿名编号**；姓名对照表自己留着，不要交）；
3. 删除示例行（编号里带"示例"的行）；
4. 运行：

```bash
python tools/pilot_analysis.py --xlsx competition/教学试点数据采集表.xlsx
```

5. 产物在 `results/pilot/`：`pilot_report.md`（统计表）+ 两张图 → 直接粘进申报书（七）4/5。

## 六、写进申报书时的如实措辞（照抄替换数字即可）

> **4. 教学试点数据**
> - 试点形式：**远程自助体验**（参与者在本人电脑上独立完成实验与前后测，非集中课堂试点），有效样本 **n = __ 人**；
> - 知识点掌握：前测 __ ± __ → 后测 __ ± __，平均提升 **__ 分**；配对 t 检验 p = __，Cohen's d = __；
> - 实验完成率 **__%**，平均完成时间 **__ 分钟**；
> - 平台满意度总均分 **__**（5 级），"愿意继续使用" **__**；
> - 所有数据匿名化处理（仅保留匿名编号），自愿参与并可随时退出。
>
> **5. 用户反馈摘录**
> （引用 3~5 条参与者原话）

**禁止**把"远程自助体验"写成"课堂试点"；**禁止**编造人数、时间、签到与照片。

## 七、做不到怎么办

若连远程也凑不到人：**如实写"方案已就绪、尚未实施"**（见 `../教学试点_极简版（10分钟_可远程）.md` 第 4 节），
拿「应用效果」第二档（7~13 分），零风险。**用第二档的分换掉取消资格的风险，是划算的。**

## 八、四条红线

1. ❌ 不把模拟/推演数据写进申报书（`tools/pilot_analysis.py --demo` 的产物只进 `results/pilot_demo/`，禁止外流）；
2. ❌ 不编造班级、人数、时间、签到表、照片；
3. ❌ 不把远程体验写成课堂试点——**做了多少写多少**；
4. ✅ 小样本、远程、非课堂——**只要如实标注，都是有效证据**。
