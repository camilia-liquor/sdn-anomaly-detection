## 四、当前已验证的关键结果（可直接引用）

**自研仿真数据集（86,037 条流记录，8 类流量，3 个随机种子）**

| 指标 | 数值 |
|---|---|
| 多分类宏平均 F1 | 0.9849 ± 0.0009 |
| 多分类准确率 | 0.9903 ± 0.0005 |
| 二分类 ROC-AUC | 0.9994 ± 0.0002 |
| TPR@FPR=1% | 0.9937 |
| 在线攻击片段召回 | 100%（24/24） |
| 平均告警时延 | 6.7 ms（P95 = 25.6 ms） |
| 误报率 | ≈14.8 次/小时 |
| 分布漂移退化 | 深度模型 ≈1%，树模型 4.5%~6.7% |

**真实公开数据集（inSDN 衍生集，343,889 条真实流记录 → 去重后 184,747 条）**

| 切分口径 | 多分类准确率 | 二分类 ROC-AUC | 误报（次/小时） |
|---|---|---|---|
| 分层随机切分 | 0.9998 | 1.0000 | — |
| 按会话分组切分（防会话泄漏） | 1.0000 | 1.0000 | 0.00 |
| 分组 + 近似重复去重（最严口径） | 0.9976 | 0.9996 | 0.51 |

> **重要（已在报告第 5.3(5) 节如实披露）**：该公开数据集 **85% 的测试样本在训练集中存在近似重复**，
> 1-最近邻基线即可达 0.9985 —— 因此这些高分**主要说明数据集冗余且易分，不代表本文方法更强**。
> 我们据此把**自研高难度仿真数据集作为主要评估基准**（该基准上随机森林仅 0.878、主模型 0.985）。
> 这一"主动诊断并披露公开数据集陷阱"的做法，正是本作品方法学严谨性的体现。
