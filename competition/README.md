| 多分类准确率 | 0.9903 ± 0.0005 |
| 二分类 ROC-AUC | 0.9994 ± 0.0002 |
| TPR@FPR=1% | 0.9937 |

1. **注册报名**：在 https://reg.aicomp.cn 注册、选「AI+开源」主题赛、缴纳 500 元参赛费
2. **建仓库并推送**：按 `05_匿名化与合规自查清单.md` 的 E 节步骤，在干净路径下初始化 git 并推送
